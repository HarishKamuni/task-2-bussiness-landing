# BrightWave Solutions — Business Landing Page

## Project Overview

BrightWave Solutions is a responsive business landing page developed as part of the WeIntern Web Development Internship — Task 2.

The website presents business services, introduces the company, and provides a contact form for visitors.

## Features

- Responsive navigation bar with a mobile hamburger menu
- Hero section with call-to-action buttons
- Services section with three service cards
- About section describing the business
- Contact form with required-field and email validation
- Footer with an automatically updated copyright year
- Responsive layouts for desktop, tablet, and mobile screens
- Smooth scrolling and interactive hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server extension

## How to Run the Project

1. Download or clone the project repository.
2. Open the `task-2-business-landing` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click the file and select **Open with Live Server**.
5. Test the website on desktop and mobile screen sizes.

## Testing

- Verified the page layout and CSS styling.
- Tested the mobile navigation menu.
- Checked the automatic copyright year.
- Tested contact form validation.
- Checked the responsive layout at different screen sizes.

## Contact Form Limitation

The contact form currently performs client-side validation and displays a confirmation message. It does not send emails or store submitted information on a server.
